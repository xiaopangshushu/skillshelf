# workspace-manager 技能

用于管理 ~/Workspace/ 下的项目索引。

## 触发场景
- 用户让你查找 Workspace 里的某个项目
- 用户在 Workspace 下新增、删除、重命名了项目文件夹
- 用户让你整理或更新 Workspace 索引

## 核心规则
1. 索引只到项目文件夹层：INDEX.md 里只记录到 work/项目名/ 这一层，不记录项目内部的具体文件。
2. 隐私边界：不要主动读取项目内部的具体文件内容，除非用户明确要求。
3. 自动维护：每次在 Workspace 下新增、删除、重命名项目文件夹后，要同步更新 ~/Workspace/INDEX.md 对应表格，并在“更新记录”里加一行。
4. 查找流程：用户让你找东西时，先读 ~/Workspace/INDEX.md 定位项目路径，再告诉用户具体位置，不要直接遍历整个 Workspace。

## 边界
- 不修改用户的项目代码
- 不删除任何项目文件
- 索引更新只做追加和修改，不覆盖已有条目
