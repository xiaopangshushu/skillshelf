# folder-organizer 技能

用于扫描指定文件夹，输出整理建议报告，帮助用户优化文件结构。

## 触发场景

- 用户说"帮我整理 ~/Desktop"或"帮我看看 ~/Documents 怎么整理"
- 用户想知道某个文件夹里有哪些文件可以合并、移走或删除
- 用户想优化某个文件夹的结构

## 核心规则

### 扫描原则

1. 只扫描到目录和文件层级，不读取文件内容，保护用户隐私。
2. 不扫描系统文件夹（如 ~/Library）和软件自动生成的目录（如 ~/Postman）。
3. 扫描结果只做报告，不主动移动或删除任何文件。

### 扫描目标规则

1. 扫描目标以用户消息中明确写出的文件夹/路径为准（通过 `/scan` 指令触发时，`/scan` 后面的全部参数都视为用户消息的一部分）；写了多个路径就全部纳入扫描。
2. 用户消息中没有指定任何路径时，才默认扫描 ~/Desktop。
3. 用户消息中的排除指令（如"绕过 XX""跳过 XX""不要扫 XX"）必须遵守：跳过的目录不进入、不统计、不报告其内容，但要在报告中列出被跳过的目录名，并注明"按要求跳过（未读取内容）"。
4. 消息中的描述性文字（如"乱七八糟""帮我看看"）不是路径，不能覆盖用户明确指定的路径；长段描述里只有明确的文件夹名/路径才改变扫描目标。
5. 指定的目标目录不存在时，直接告知用户并停止，不要擅自改扫其他目录。

### 建议类型

1. **合并建议**：多个文件夹/文件明显属于同一类（如 react-xxx、vue-xxx），建议合并到同一个父目录下。
2. **移走建议**：文件/文件夹更适合放到 ~/Workspace/ 的对应分类下（work/、part-time/、personal/、study/、references/），建议移走并指出目标路径。
3. **删除建议**：只对空目录、临时文件（.DS_Store、.tmp、~$ 开头的文件）、明显的重复文件提出删除建议，绝不建议删除任何文档或代码。
4. **保留建议**：系统文件夹、软件自动生成的目录，建议保留不动。
5. **新建建议**：如果发现某类文件/文件夹在当前目录下没有合适归属，且 ~/Workspace/ 下也没有对应分类，建议新建一个分类文件夹，并说明应该建在哪、叫什么名字。
6. **归档建议**：如果发现桌面或下载目录里的文件更适合归档，建议移入 `~/Archive/` 对应子目录，并明确指出目标路径：
   - 文档/资料类（PDF、电子书、报表等）→ `~/Archive/documents/`
   - 图片/截图类 → `~/Archive/pictures/`
   - 软件安装包（dmg、vsix、sdk、zip 安装包等）→ `~/Archive/installers/`
   - 视频、音频 → `~/Archive/media/`
   - 游戏相关 → `~/Archive/games/`
   - 不好归类的 → `~/Archive/misc/`

### 执行规则

1. 必须先输出完整建议报告，等用户确认。
2. 用户明确说"执行"后，每次只执行一条建议，执行完等用户确认再执行下一条。
3. 不要一次性执行多条建议。
4. 不要删除任何文档或代码，只删除空目录、临时文件和重复文件。

### 隐私边界

- 不读取任何文件的具体内容。
- 如果某个文件夹名字看起来涉及隐私（如"私人""身份证""合同"），跳过不扫描，并告诉用户。
- 遇到 `~/SnippetsLab/` 或名称包含"SnippetsLab"的文件夹，直接跳过，不扫描、不读取、不报告。

## 使用示例

用户说："用 folder-organizer 扫描 ~/Desktop，给我整理建议。"
→ 扫描 ~/Desktop。

用户说："扫描 ~/Downloads，绕过 ~/Downloads/个人信息，给我整理建议。"
→ 只扫描 ~/Downloads；报告中列出"已按要求跳过：个人信息（未读取内容）"；不要去扫描 ~/Desktop。

用户说："用 folder-organizer 给我整理建议。"（未指定路径）
→ 默认扫描 ~/Desktop。

Agent 应该输出一份报告，包含：

- 目标文件夹的文件和文件夹清单（只到目录层级）
- 每条建议，按类型分组：合并 / 移走 / 新建 / 删除 / 保留
- 每条建议后面注明理由
- 等用户确认后再执行

用户确认后，每次只执行一条建议，执行完等用户确认再执行下一条。
